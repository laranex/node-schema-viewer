# Agent skills

::: info Planned
This repository does not publish [Agent Skills](https://github.com/vercel-labs/skills) yet, so there is nothing to install with `npx skills add` for Node.js today.
:::

Planned skills will help coding agents install the package, open the viewer, connect MCP, and interpret comparisons and drift-gate reports, as python-schema-viewer's [agent skills](https://laranex.github.io/python-schema-viewer/agent-skills.html) do for Python.

Until then, connect your agent to a document with the read-only [MCP server](./mcp.md): its six tools cover the overview, search, tables, models, relationships and stored comparisons. Because the document and the tool responses follow the shared laranex-schema contract, the MCP responses are the same as python-schema-viewer's for the same document.
